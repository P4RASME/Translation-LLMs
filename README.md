# Unsupervised translation

adversarial_training.py- Built discriminator and map models to train in an adversarial manner to map two word embeddings in english and spanish.  Inspired by the paper 'Translation without parallel data'. 

embeddings.py- training the aforementioned word embeddings.  Used open subtitles v2018 database for this.
